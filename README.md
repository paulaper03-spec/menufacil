# MenúFácil 📱🥗

*MenúFácil* es una aplicación móvil diseñada para facilitar la creación de menús saludables y económicos. El objetivo principal es ayudar a los usuarios a planificar sus comidas diarias de forma equilibrada, optimizando su presupuesto y fomentando hábitos de vida saludables.

## 🚀 Características Principales

* *Planificación Inteligente:* Generación de menús diarios y semanales equilibrados.
* *Control de Presupuesto:* Filtros y sugerencias basadas en ingredientes económicos y accesibles.
* *Gestión de Recetas:* Base de datos con opciones saludables y pasos sencillos de preparación.
* *Interfaz Móvil:* Diseño adaptado, intuitivo y fácil de usar en smartphones.

## 🛠️ Tecnologías y Estructura

El repositorio contiene el prototipo y los archivos base para el desarrollo de la aplicación móvil:
* MenuFacil_prototipo_.movil - Archivo fuente del prototipo/especificación del diseño.
* Código base de la aplicación organizado para su despliegue en entornos móviles.
